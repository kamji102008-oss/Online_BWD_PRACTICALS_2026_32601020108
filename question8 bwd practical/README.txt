HOW TO RUN IN VS CODE (ON YOUR PC)
1. Extract the complete ZIP folder. Do not open index.html from inside the ZIP.
2. In VS Code choose File > Open Folder and select the extracted TechNova_Assignment_8 folder.
3. Confirm that index.html, style.css, script.js and the assets folder are all visible.
4. Right-click index.html > Open with Live Server.

MEDIA FIX
The audio and video are now included inside the assets folder. They do not need an internet connection.
Keep the assets folder beside index.html. If you move index.html alone, the media will not load.
