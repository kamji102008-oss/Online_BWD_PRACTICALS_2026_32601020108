BCA PRACTICAL ASSIGNMENT 20
Project: Multi-page College Website

FILES
- index.html: Home page
- about.html: About page
- courses.html: Courses page
- contact.html: Contact form page
- style.css: External CSS styling
- script.js: JavaScript form validation and message

HOW TO RUN IN VS CODE
1. Extract this ZIP file.
2. Open VS Code.
3. Select File > Open Folder and choose Assignment_20_College_Website.
4. Open index.html.
5. Right-click and select Open with Live Server (if Live Server extension is installed).
6. Use the navigation bar to open the other pages.

HOW TO PUBLISH USING GITHUB PAGES
1. Sign in to GitHub and create a new public repository.
2. Upload all project files and keep them together in the repository's root folder.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the website. Open the displayed website link in a browser.

NOTE
Bootstrap is loaded from a CDN, so an internet connection is required for Bootstrap styling and components. The contact form is a front-end demonstration; it does not send data to a college server.
